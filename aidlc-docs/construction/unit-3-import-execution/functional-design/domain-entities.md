# Domain Entities — Unit 3: Import Execution & Results Service

## Overview
Unit 3 operates on validated data passed from Unit 2. It creates persistent records in the database and returns structured results. No new collection schemas are introduced — Unit 3 writes to existing collections.

---

## Input Entities (Received from Unit 2)

### 1. ValidatedRow
The input contract data passed from Unit 2 after all 5 validation levels pass.

| Attribute | Type | Description |
|-----------|------|-------------|
| rowNumber | number | 1-based row number from source CSV |
| contractNumber | string | Validated contract number |
| isValid | boolean | Always true when passed to Unit 3 |
| data | ContractImportData | All 25 parsed and typed field values |

### 2. ContractImportData
See Unit 2 domain-entities.md for full field list. All fields are pre-validated and typed.

---

## Runtime Entities (In-Memory, Not Persisted)

### 3. ReferenceResolutionResult
Result of resolving a single reference data name to a database ID.

| Attribute | Type | Description |
|-----------|------|-------------|
| id | string | MongoDB ObjectId of the resolved or created record |
| wasCreated | boolean | True if a new record was created, false if existing was reused |
| entityType | "Party" \| "Commodity" \| "PaymentTerm" \| "BankDetails" | Type of reference |
| name | string | The name that was resolved |

### 4. ResolvedContractData
A single row's data after all reference names have been resolved to ObjectIds, ready for contract creation.

| Attribute | Type | Description |
|-----------|------|-------------|
| rowNumber | number | Source row number |
| contractNumber | string | Contract number |
| contractDate | Date | Parsed date |
| buyerId | ObjectId | Resolved buyer Party ID |
| sellerId | ObjectId | Resolved seller Party ID |
| commodityId | ObjectId | Resolved Commodity ID |
| paymentTermId | ObjectId | Resolved PaymentTerm ID |
| bankDetailsId | ObjectId | Resolved BankDetails ID |
| quantity | number | Quantity |
| unit | string | Unit enum |
| tolerance | number | Tolerance percentage |
| unitPrice | number | Unit price |
| currency | string | Currency code |
| totalAmount | number | Calculated: quantity × unitPrice |
| totalAmountText | string | Generated by numberToText utility |
| minQuantity | number \| null | Calculated if tolerance > 0 |
| maxQuantity | number \| null | Calculated if tolerance > 0 |
| minTotalAmount | number \| null | Calculated if tolerance > 0 |
| maxTotalAmount | number \| null | Calculated if tolerance > 0 |
| paymentTermText | string | Set to paymentTermName from CSV |
| origin | string | Origin |
| packing | string | Packing |
| qualitySpec | string | Quality spec |
| incoterm | string | Incoterm enum |
| portLocation | string | Port location |
| shipmentPeriod | string | Shipment period |
| additionalTerms | string | Additional terms |
| releaseType | string | Release type enum |
| status | string | Status enum |
| createdBy | string | Admin userId passed from Unit 2 |

### 5. ImportRowResult
Result of attempting to import a single row.

| Attribute | Type | Description |
|-----------|------|-------------|
| rowNumber | number | Source row number |
| contractNumber | string | Contract number |
| status | "imported" \| "failed" | Outcome |
| contractId | string \| null | MongoDB ObjectId of created contract |
| error | string \| null | User-facing error message if failed |
| createdReferenceData | CreatedReferenceData | Summary of what reference data was created |

### 6. CreatedReferenceData
Tracks which reference records were newly created during this row's import.

| Attribute | Type | Description |
|-----------|------|-------------|
| buyer | string \| null | Name of newly created buyer, or null if reused |
| seller | string \| null | Name of newly created seller, or null if reused |
| commodity | string \| null | Name of newly created commodity, or null if reused |
| paymentTerm | string \| null | Name of newly created payment term, or null if reused |
| bankDetails | string \| null | Bank name of newly created bank details, or null if reused |

## Persistent Entities Written (Existing Collections)

### 7. Party (existing collection)
Created when buyer or seller name not found in DB.

| Field | Value set by import |
|-------|-------------------|
| companyName | buyerName or sellerName from CSV |
| type | "BUYER" or "SELLER" |
| address | "To be updated" |
| isActive | true |
| contactPerson | (not set) |
| email | (not set) |
| phone | (not set) |
| country | (not set) |
| taxId | (not set) |

### 8. Commodity (existing collection)
Created when commodityName not found in DB.

| Field | Value set by import |
|-------|-------------------|
| name | commodityName from CSV |
| description | commodityDescription from CSV |
| defaultUnit | unit from CSV |
| defaultOrigin | origin from CSV |
| defaultPacking | packing from CSV |
| isActive | true |
| hsCode | (not set) |

### 9. PaymentTerm (existing collection)
Created when paymentTermName not found in DB.

| Field | Value set by import |
|-------|-------------------|
| name | paymentTermName from CSV |
| description | "Imported" |
| terms | "Imported" |
| isActive | true |
| depositPercentage | (not set) |
| daysFromBL | 0 (default) |

### 10. BankDetails (existing collection)
Created when (bankName + accountNumber + swiftCode) not found in DB.

| Field | Value set by import |
|-------|-------------------|
| bankName | bankName from CSV |
| accountName | accountName from CSV |
| accountNumber | accountNumber from CSV |
| swiftCode | swiftCode from CSV |
| currency | currency from CSV |
| isActive | true |
| bankAddress | (not set) |
| iban | (not set) |
| isDefault | false |

| incoterm | from CSV |

| totalAmount | calculated: quantity × unitPrice |
| totalAmountText | generated by numberToText utility |
| paymentTerm | resolved paymentTermId |
| paymentTermText | paymentTermName from CSV |
| bankDetails | resolved bankDetailsId |
| minQuantity | calculated if tolerance > 0 |
| maxQuantity | calculated if tolerance > 0 |
| minTotalAmount | calculated if tolerance > 0 |
| maxTotalAmount | calculated if tolerance > 0 |
| shipmentPeriod | from CSV |

| releaseType | from CSV (default NOT_SPECIFIED) |
